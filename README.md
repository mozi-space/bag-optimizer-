# 法宝背包摆放优化器 · 觉醒版

支持每件法宝独立选择觉醒 0–5 级。计算固定为战力最大化、强制填满、30 秒和 12 线程。持有法宝不足或形状不能完全填满时，会返回可找到的摆放方案。

所有脚本、样式、数据和后台计算程序已包含在 index.html，可离线打开，也可用 GitHub Pages 从 main 分支根目录发布。无需设置自定义域名。
